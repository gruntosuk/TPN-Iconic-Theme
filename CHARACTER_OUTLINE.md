# Character outline (generic Gemini brief)

Use this to add a character to a finished background so it fits the rest of the theme.
Attach the current background image, fill in the character line, and paste.

```
Edit the attached background image by adding one character into it. Keep the scene, composition, palette, lighting and every existing object exactly as they are. Only add the character.

CHARACTER (add the specifics here): [who, outfit, pose, what they are holding]

STYLE AND FIT
- Match the background's hand-painted illustration style: visible painterly brushwork, soft edges and slightly simplified shapes. It must look like it was painted in the same session as the scene, not a photo, a 3D render or a pasted cut-out.
- Match the existing lighting. Light the character from the same direction and in the same colours as the scene, so the light colour spills onto them. Add a soft rim light along the edge facing the main light source.
- Match the colour grade. Pull the character's colours toward the scene's palette and keep contrast and saturation similar to the background. No bright white highlights or pure black shadows unless the scene has them.
- Ground them in the scene. Add a soft cast shadow under or beside them that follows the ground and the light direction. Add a little atmospheric haze or glow, where it fits, so they sit inside the same air as the background.
- Keep the edges painterly, with no hard cut-out outline or white halo.

PLACEMENT AND SCALE
- Place the character in the right 55 percent of the image, standing on a believable surface in the scene.
- Make them about one third of the image height, so they read clearly but the scene is still visible around them.
- Full body in frame, not cropped, with some breathing room around them. Avoid placing them over the brightest or busiest part of the scene.
- Do not change, move or remove anything in the left 45 percent. It stays empty.

DO NOT
- No text, logos, UI, watermarks or captions.
- Do not add extra characters, props, creatures, signs or light sources, other than anything the character is holding.
- Do not change the background, the weather or the time of day.
```

## Tips
- Check the left 45 percent and the background after each try; Gemini often changes more than asked. If it adds junk, ask it to remove only that item.
- Do not put "1080p" in the prompt (it added clutter). Say "keep the same image size and framing" if needed. Fitting to 1920x1080 is done afterwards.
- Character too small or large: change the "about one third of the image height" line (for example "about 40 percent").
- Send the result back for a left-side check, fit, install and mockup re-render.
